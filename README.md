## Entry

Professional Mourner for Strangers

## How it works

Run `python3 main.py`. It writes the job title to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `out`), as UTF-8 bytes with no trailing newline, then validates the file: a single line, 1-60 characters, no carriage return, no leading or trailing whitespace, content matching the title. Two runs produce byte-identical output.
